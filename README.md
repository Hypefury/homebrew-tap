# homebrew-blackroija

Homebrew tap for [blackroija](https://github.com/Hypefury/blackroija).

```bash
brew install hypefury/blackroija/blackroija
```

It builds from source, so it needs the Xcode command line tools (`xcode-select --install`). To start it now and at every login:

```bash
brew services start hypefury/blackroija/blackroija
```

The formula follows the newest `v*` tag of the app's repo; a workflow here updates it within the hour.
